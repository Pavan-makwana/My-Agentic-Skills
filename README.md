## 🏛️ System Architecture

```mermaid
flowchart TD
    User["User: Enter Song Title or YouTube Link"] --> Master["Skill: song-to-reel-pipeline"]
    
    subgraph Ingestion
        Master --> YT["Skill: youtube-media-extractor"]
        YT --> Audio["48kHz Studio Audio (MP3/WAV)"]
    end

    subgraph Synchronization
        Audio --> Sync["Skill: lyric-word-sync-engine"]
        Sync --> Onset["Acoustic Onset & Syllable Weights"]
        Onset --> WordMap["Word-by-Word Timestamps JSON"]
    end

    subgraph Visual Synthesis
        WordMap --> Art["Skill: canvas-line-art-generator"]
        Art --> CoupleSVG["Traditional Couple SVG (Saree & Dhoti)"]
        WordMap --> Canvas["1080x1920 Paint Frame Canvas"]
    end

    subgraph Rendering
        Canvas --> Render["Skill: paint-frame-reel-renderer"]
        Render --> Puppeteer["Headless Chrome (DeviceScale 1.0)"]
        Puppeteer --> Concat["FFmpeg Concat Demuxer Script"]
        Concat --> Video["1080x1920 9:16 Vertical Reel (H.264/AAC)"]
    end

    subgraph Distribution
        Video --> Telegram["Skill: telegram-reel-publisher"]
        Telegram --> Bot["@PeakLyricsBot"]
        Bot --> Chat["User Telegram App & Channels"]
    end
```

## ⚡ Quickstart: Installing into Antigravity

### 1. Global Installation (Recommended)
Copy all skills into your local Antigravity configuration directory:
```bash
# Windows PowerShell
Copy-Item -Recurse -Force skills/* "$env:USERPROFILE\.gemini\config\skills\"

# macOS / Linux
cp -r skills/* ~/.gemini/config/skills/
```

### 2. Workspace Project Installation
Place inside your project's `.agents/` folder:
```bash
mkdir -p .agents/skills
cp -r skills/* .agents/skills/
```

Antigravity will automatically discover all skills via **Progressive Disclosure**.

## 🛠️ Tech Stack & Requirements

- **Runtime:** Node.js v20+ / v22+
- **Media Engine:** FFmpeg v7.0+ (with `libx264` and `aac`)
- **Browser Automation:** `puppeteer-core` with Google Chrome
- **Audio Processing:** Python 3.10+ (`numpy`, `wave`, `speech_recognition`)
- **Downloader:** `yt-dlp`
